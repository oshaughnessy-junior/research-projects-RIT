# Build-tool bounds for pygsl_lite 0.1.8, which pyseobnr depends on and which
# has no wheels, so every container build and canary run compiles it.
# These constrain isolated build backends only; runtime dependencies in
# requirements-container.txt remain intentionally unpinned.
#
# pygsl_lite 0.1.8 still calls distutils.util.spawn(cmd, 1, 1).
# setuptools 84 made every argument after cmd keyword-only.
setuptools<84
#
# pygsl_lite 0.1.8 regenerates its SWIG wrappers at build time, and its
# typemaps/misc_typemaps.i calls the Python 2 name PyInt_FromLong.
# SWIG 4.4.1 still defines it as PyLong_FromLong; SWIG 4.5.0 (2026-08-21)
# dropped that, so block_wrap.c fails to compile.  RIFT's own SWIG lane is
# tested separately (pixi swig-post44, container-swig-canary).
swig<4.5
#
# Remove each bound once a pygsl_lite release contains the upstream fix.
